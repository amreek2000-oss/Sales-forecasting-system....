## 📌 Executive Summary

The **Sales Forecasting System** is an end-to-end Machine Learning project designed to analyze historical business sales data, compute monthly revenue growth trends, and forecast future sales trajectory using **Linear Regression**. 

This system processes transactional records, handles dataset preprocessing, generates model performance evaluation metrics ($R^2$ Score, RMSE), and outputs prediction charts along with strategic business insight reports.

---

## 🎯 Cognevance Project Requirements Coverage

* **Task 1 & 2**: Data Collection & Preprocessing (Handling datetime variables, missing values, and discount calculations).
* **Task 3**: Monthly and Yearly Sales Trend Analysis.
* **Task 4**: Utilization of Python analytics libraries (`Pandas`, `NumPy`, `Matplotlib`, `Scikit-Learn`).
* **Task 5**: Implementation of Time-Series Linear Regression forecasting model.
* **Task 6**: Prediction visual charts showing historical trends vs future forecast.
* **Task 7**: Comprehensive Business Insights Report detailing findings and inventory strategy.
